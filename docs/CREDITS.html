Privacy, costs & browser limits

  • Local engines: audio/text inference stays in your browser. Downloads contact Hugging Face and runtime asset hosts. Hosting on GitHub Pages does not provide an inference server.
  • Hosted engines/word lookup send audio or text to the endpoint you explicitly authorize. Keys are kept only in tab-session memory. No keys are bundled, persisted to preferences/library, or included in exports. This is not Android Keystore protection.
  • No automatic provider fallback/retry, no developer-run paid test calls. Set hard spending limits at the provider: a browser app cannot enforce your account's included-credit balance or stop provider-side overage billing. Accepted/cancelled jobs can still incur charges and retention.
  • IndexedDB holds your local audio/transcripts. Browser site-data clearing or storage eviction can delete them; export important work. Deleting locally does not delete uploaded provider data.
  • Queues require an open, active tab. No guaranteed Android-style background work, charging/Wi-Fi enforcement, or screen-off processing. Native Vosk, its speaker clusters, whisper.cpp/JNI/GGML, JNA and Google ML Kit are not bundled. RSS/Atom subscriptions, directory discovery, queues and publisher transcript/chapter loading are browser implementations. Android data access, gpodder sync, Cast, Android Auto, Wear OS and widgets are not implemented. Some publishers block CORS; only an explicitly authorized user-configured proxy can relay those requests.
  • Models are imperfect. No invented speaker identities, word timestamps or universal-language claims. Translation synchronizes to source segments; target-language word timings are not measured. Word lookup is machine translation, not a dictionary.
  • No AntennaPod logos, upstream artwork/screenshots, commercial fonts, podcast recordings or third-party design templates are shipped. The only third-party branding assets are Google's required, unmodified translation-attribution badges, subject to Google's brand terms. Original CSS uses system fonts and simple text controls. Local inference validation may use the JFK speech sample from whisper.cpp as a test input only; it is not bundled as application media.
